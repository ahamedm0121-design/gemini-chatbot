# Gemini AI Chatbot

Simple chatbot using Google Gemini 3.5 / 3.8 Flash

## Setup
1. Clone repo
2. Create .env file with GOOGLE_API_KEY=your_key
3. pip install -r requirements.txt
4. python main.py

## Models tested
- gemini-2.5-flash (deprecated)
- gemini-3.5-flash (stable)
- gemini-3.8-flash (latest)
